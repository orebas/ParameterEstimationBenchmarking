_Generated by `results/wallaby_analysis/rank_strategy_topM_ablation.py`._


**SCOPE-LIMITED:** This ablation only re-ranks the M=1 or M=2 rows that survived ODEPE's clustering + ranking + diversity selection at runtime. The pre-truncation candidate pool (which is what the rank strategy actually operates on inside ODEPE) was not dumped on Wallaby. So this script shows only the **truncation-step** effect of the rank strategy on a tiny pool (1 or 2 rows per cell).


A proper rank-strategy ablation requires re-running with `dump_raw_candidates_path` enabled. Deferred to Quoll smoke/pilot per the publication roadmap.

## Interpretation


If the M=2 truncated pool is well-curated (the cluster step already picked the M correct branches), then re-ranking those 2 rows under different strategies just swaps WHICH of the M algebraic branches becomes row 0 — both rows are likely truth-near, so the swap doesn't change Best-of-branches @10% (= argmin over the 2 rows). It only changes top-pick @10% (= row 0 only).


This is the limited effect that's observable here. The interesting rank-strategy effect upstream — where a 700-candidate pool gets ranked and the top 20 retained for clustering — is NOT visible from stored data. Quoll smoke/pilot with `dump_raw_candidates_path` enabled will measure this properly.
