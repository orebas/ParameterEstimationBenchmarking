# Archived templates

Templates moved here are no longer wired into active benchmarks but are preserved
for reproducibility of older benchmark snapshots.

## ODEPE kernel-variant templates (archived 2026-05-06)

`julia_template_for_estimation_odepe_kernel_{se,rq,se_plus_rq,se_times_rq}.jl`

These were single-interpolator ODEPE templates that fixed `interpolator =
InterpolatorAGPRobust{,RQ,SEpRQ,SExRQ}` respectively. Used in earlier benchmarks
to compare GP kernel choices in isolation. Superseded by the Numbat-era
multi-interpolator portfolio:

- `templates/julia_template_for_estimation_odepe_v2.jl` runs the package-default
  9-interpolator list with multipoint + synthesize_aggregate_candidates.
- `templates/julia_template_for_estimation_odepe_shade.jl` is the SHADE+LM hybrid
  baseline.

The harness (`src/generate_scripts.py`, `src/shared.py`) still references the
kernel-variant template paths in dispatch dicts so older benchmark
snapshots (e.g. `benchmark_bilby_2026_03_09/`) can still be regenerated by
restoring these files. They are intentionally kept on disk rather than deleted.
